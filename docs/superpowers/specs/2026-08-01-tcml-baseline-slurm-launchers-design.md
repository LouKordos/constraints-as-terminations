# TCML Baseline Slurm Launchers Design

**Date:** 2026-08-01

**Status:** Awaiting written-specification review

## Purpose

Create directly runnable Slurm launchers on `tcml-cluster` for training the
matched Go2, ANYmal-C, and Spot reward-based baselines with nine seeds each.
Preserve the scheduling conventions generated by
`create-isaac-lab-env-uv.sh` and make only the embodiment-specific changes
needed to launch the baseline recipes.

Create six standalone files:


Each file must be directly submit-able with `sbatch` and must not require an
embodiment argument or a shared wrapper.

## Scheduling

All launchers train seeds `46` through `54`, for nine runs per embodiment and
hardware variant.

The L40S launchers preserve the generated multi-run layout:

- partition: `L40Sday`
- GPU request: `gpu:L40S:1`
- array: `0-2%3`
- runs per allocated GPU: `3`
- each array task launches three seed processes concurrently

The 2080 Ti launchers preserve the generated single-run layout:

- partition: `week`
- GPU request: `gpu:2080ti:1`
- array: `0-8%9`
- runs per allocated GPU: `1`

CPU, memory, time, mail, environment, startup staggering, failure aggregation,
and current W&B authentication setup remain identical to the respective
generated template. Credential values must not be printed during inspection,
generation, or validation.

## Training Commands

Each embodiment uses its existing public `just` recipe with `NUM_ENVS=7500`
and the selected seed:

```bash
just train-baseline-go2 "${NUM_ENVS}" "${seed}"
just train-baseline-anymal-c "${NUM_ENVS}" "${seed}"
just train-baseline-spot "${NUM_ENVS}" "${seed}"
```

The recipes already provide:

- `max_iterations=30000`
- W&B logging
- projects `baseline_go2`, `baseline_anymal_c`, and `baseline_spot`
- the matching `Baseline-*-Rough-Terrain-v0` task ID

Job names must identify both the embodiment and, for the week-partition files,
the 2080 Ti variant. Output and error paths retain the existing job-ID-based
naming, which prevents collisions between submissions.

## Validation and Safety

Before modifying the remote environment, stage the six complete files locally
and inspect their differences from the two source templates. Transfer them to
the remote environment only after local syntax and content checks pass.

Validate on `tcml-cluster` without launching Isaac Lab or submitting jobs:

- `bash -n` succeeds for every new file.
- every file contains exactly nine seeds, `46` through `54`.
- L40S files contain `0-2%3` and `RUNS_PER_NODE=3`.
- 2080 Ti files contain `0-8%9` and `RUNS_PER_NODE=1`.
- each file invokes exactly one correct `train-baseline-*` recipe.
- public and shared `just --dry-run` expansion confirms 7,500 environments,
  30,000 iterations, W&B logging, and the correct project name.
- the remote Git checkout remains clean and unchanged.

Do not run `sbatch`, start a simulator, start training, or start evaluation.
